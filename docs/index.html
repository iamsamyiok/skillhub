llms.txt 索引

LLM/Agent 可读的站点索引，含全部技能与用法。

GET /llms.txt

技能清单

纯文本一行一技能：名称、分类、描述、下载地址。

GET /skills.txt

JSON API

结构化元数据检索，支持 q 与 category 参数。

GET /api/skills?q=图

打包下载

tar.gz 全量文件，含 SKILL.md 与脚本资源。

GET /api/skills/{id}/download
