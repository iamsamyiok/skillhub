MCP 配置指南

下载后参考以下配置方式接入主流编辑器。

Claude Desktop

编辑 ~/.claude/settings.json，添加 mcpServers 配置。

{ "mcpServers": { "my-mcp": { "command": "node", "args": ["server.js"] } } }

Cursor / VSCode

通过 MCP 扩展管理服务器，或直接编辑配置文件。

GET /api/mcps/{id}/config → 下载 JSON

一键配置

获取标准配置的 API 端点。

curl /api/mcps/{id}/config -o ~/.config/mcp.json
