# Skill: text-to-image（文字转图片）

把用户的文字描述转成高质量 prompt，驱动文生图服务异步生成图片，并轮询至出图。

## 何时使用

- 用户想要从零生成一张图：海报、插画、产品概念图、营销素材、角色/场景视觉草案
- 用户只给了文字描述（无参考图）
- 有参考图要改 → 走图片编辑流程（image_generate_edit_image），本技能只管纯文生图

## 标准工作流

1. **组织 prompt（决定出图质量的关键）**。尽量覆盖：
   - 主体：画什么，视觉焦点
   - 场景/背景：在哪里、什么氛围
   - 风格：写实/扁平插画/水彩/赛博朋克/极简……
   - 构图与视角：特写/全景/俯视/居中对称……
   - 光影与色彩：逆光/柔和晨光/高饱和/莫兰迪色……
   - 细节要求：文字元素、留白、质感
2. **选比例 ratio**（可选，默认 auto）：

   | 用途 | 建议 ratio |
   |------|-----------|
   | 头像、图标、方图社交帖 | 1:1 |
   | 公众号封面、横幅 | 16:9 |
   | 海报、手机端封面 | 3:4 |
   | 手机壁纸、短视频封面 | 9:16 |
   | PPT 插图、博客配图 | 4:3 |

3. **发起任务**：调用 `image_generate_text_to_image(prompt, ratio)`，返回 task_id（此时不会立即有图）。
4. **轮询结果**：用 `image_generate_query_task(task_id)` 查询，10-30 秒一次；通常 **1-5 分钟** 完成。status 含义：
   - `processing` 排队中 / `running` 生成中 → 继续等
   - `completed` → 才向用户展示 `image_urls`
   - `failed` → 向用户说明失败原因，并建议 `image_generate_retry_task` 重试
5. **数量不足**：completed 但图片少于预期 → 调 retry 补齐。

## 注意

- 生成耗时 1-5 分钟：先告知用户"正在生成，约 1-5 分钟"，再轮询，避免用户干等
- task_id 未 completed 时 `image_urls` 恒为空数组，提前展示是错的
- prompt 用具体名词与画面语言；抽象形容词（"高级感""大气"）效果差，换成可画出来的描述（"大面积留白+金色细线+深蓝底"）
