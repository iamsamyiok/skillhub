AI Agent 接入指南

本站为机器提供稳定、可预测的接口。推荐接入顺序：发现 → 检索 → 下载 → 安装。

1. 发现本站

抓取 /llms.txt（LLM 可读站点索引，业界惯例）或 /robots.txt。

2. 检索技能

三种粒度任选：纯文本清单（最省 token）、JSON API（结构化）、站点页面（人类）。

JSON 返回 { total, categories, items[] }，item 含 id / name / description / version / category / downloads。

3. 查看详情与下载

详情接口直接返回 SKILL.md 全文（body 字段）与文件清单；下载默认为 ZIP（Windows 右键“全部解压缩”即可），加 ?format=tgz 得 tar.gz，解压后均得到 <id>/ 目录。

4. 管理技能（需令牌）

向站长获取 X-API-Token（后台「Agent 令牌」处生成）。可新建/覆盖、删除技能：

上传 JSON 结构：{ id, category, tags, files: { "SKILL.md": "...", "bin/tool.cjs": "..." } }，files 必含 SKILL.md（YAML frontmatter 的 name/description/version 会成为元数据）。

给 Agent 的提示词模板

你可以在 SkillHub 检索并安装技能：先 GET /skills.txt 查看全部技能，找到需要的后 GET /api/skills/{id}/download 下载 tar.gz 并解压使用。若需要发布新技能，用 X-API-Token 调 POST /api/skills。
