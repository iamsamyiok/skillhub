# 一、核心思想（philosophy）

> 来源：Cheng Lou 的 **handwired** —— https://github.com/chenglou/handwired
> 口号：*"Turn your regular JavaScript code into a neural net; no training, exact, yet also fully differentiable!"*

传统只有两条路：

- **程序（白盒）**：人写每一步，精确但死板、难自适应；
- **机器学习（黑盒）**：给数据让它学，自适应但不确定、难审计。

handwired 走中间地带：**从一个精确程序出发，编译成可微表示，之后只让"你愿意改的地方"变得可训练。** 学习不再是系统诞生的机制，而成了精炼机制。

本 skill 把这一思想工程化，落地为「规则约束下的机器学习」：**先把手头的领域知识写成一条结构化规则（明规则），再让梯度只去调你没把握的那几个幅度系数。**

## 可微化的唯一技巧：用 ReLU 把控制流变成算术

```js
// 你写的规则
const result = (a > 4) ? 10 : 12
// 编译后（纯 +、*、ReLU）
const above4 = Math.max(0, a - 4) - Math.max(0, a - 5)  // a>4 时为1，否则为0
const result = above4 * 10 + (1 - above4) * 12
```

`above4` 是一个「0 或 1」的选择器。把所有 `+`、`*`、ReLU 收集起来，就是一个可微计算图——能求梯度、能上 GPU、但数值上和原 if-else **完全等价**。到这一步「什么新功能都没有」，只是换了种写法（精确、无需训练）。

**真正能做的事**：把算式里的 `10` 这个常数，从「写死」变成「可学习的旋钮」——冻结结构，只解冻这一个数字，喂数据让梯度把它从 10 调到 8。**规则结构从头到尾没动过，也没训练任何模型。**

## 四分类法（本 skill 的灵魂）

对程序里**每一个数 / 决策点**做四分类，比「输入→输出」的变量框架更根本：

| 分区 | 含义 | 是否更新 | 例子 |
|------|------|---------|------|
| **冻结（白盒）** | 必须成立的逻辑 / 安全 / 物理约束 | 永不 | "pH>9 必停泵""存款≥0""够湿不浇" |
| **可训练（灰盒）** | 你没把握的幅度 / 系数 / 阈值 | 梯度更新 | "浇多少 ml""高学历多值几万" |
| **受限可变** | 能调但永远不越界 | 更新但夹紧 | "默认量≤X""子女系数∈(−∞,0]" |
| **仅可微不训** | 固定但用来算敏感度 | 不动 | "输出对哪个参数最敏感" |

> 把"确定性逻辑写死、把不确定性留作可训练口子"——这就是 handwired 的本质，也是本 skill 全部价值的来源。

## 与本 skill 的映射

- 冻结 / 受限 → 写在 **recipe 配方**里（结构、符号、地板、膝点），生成代码在结构层保证，训练绝不会改；
- 可训练 → 生成代码的 `raw` 参数，训练时只更新这些；
- 训练产物 → 一条**可读规则 + 调好的幅度系数**，而非黑盒权重堆。
