# Changelog — pre-align

## 2.5.0 (2026-10-17)

苏格拉底诘问法升级（缘起：李飞飞「苏格拉底是人类历史上最好的提示词工程师」——诘问法的本质是设计问题让对方自己产出真理）：

- 出题门「苏格拉底三问」：每道题构造前自检——答案会改变方案吗 / 这个信息我查得到吗（查过要注明已查哪里）/ 默认值说得出出处吗；纯猜测的默认值降级进 🧾 假设段。
- 术语钉（定义先行）：目标段模糊名词必须内联钉死定义（「迁移」=…），钉不动的升级为「要你定」一题。
- 归谬句式：🔴 盲区固定「按现方案 → 会发生（可观察的具体后果）→ 与（事实/你的另一条要求）冲突」，禁用「有风险」「需注意」等抽象警告词。
- 新增反模式「不吞矛盾」：答复之间或答复与事实冲突时当场指出请用户裁决，选边须留决策日志。
- 产婆术收口：访谈共识清单关键决策引用用户原话，AI 补全解读标注「我说」；网页读单后决策日志区分「用户原话 / AI 解读」。

## 2.4.0 (2026-10-12)

默认值标识重构：

- 去掉「默认 · X」文字徽标；默认选项直接以绿色描边环（2.5px 绿环）标在 chip 上，选中态正常覆盖。
- yesno 默认侧加绿环；multi 支持 def 为索引数组时多绿环。
- 文本题默认值改为绿色药丸，点击一键回填输入框。
- 「要你定」段标签改为「点选 · 绿框为默认」作图例。


## 2.3.0 (2026-10-12)

题量解绑：

- 网页模式题量按需设置、不设上限——每题自带默认值，用户可整页跳过点「按默认开工」，多问代价低；唯一保留的质量闸是「会改变方案才问」。
- 删除网页模式对文本简报字数预算（问题 ≤22 字、理由 ≤28 字）与 1-5 题区间的硬性引用。
- 访谈档判据改为「问题相互依赖（树状追问）或用户明说深度对齐」，与题量脱钩。


## 2.2.0 (2026-10-12)

条目级补充输入：

- 看板每个编号条目（目标/要你定/假设/盲区/验收）自带一个选填输入框，虚线边框弱视觉、聚焦变实，placeholder 按段落语义区分（自定义答案 / 想改就写怎么改 / 对盲区的答复 / 补充细节）。
- 输出协议新增 `notes` 字段（id -> 文字，仅含非空项）；SKILL.md 明确读单规则：notes 优先于选项与默认值，红色盲区有 notes 视为已答复。
- 成功页摘要逐条回显 notes。


## 2.1.0 (2026-10-12)

实测反馈修复：

- 看板改浅色主题：暖白底 + 白卡片 + 蓝紫渐变强调，交互组件（chips/开关/输入/警示卡）全部重配浅色配色。
- 打通「提交后自动接单」：Agent 侧流程升级为五步——发出看板后同轮挂**有界文件等待**（`timeout 600 bash -c 'until [ -f align-output.json ]; do sleep 2; done'`），用户点提交的瞬间文件落盘、等待返回、Agent 同轮读单开工，全程无需用户再打字；超时转异步（任一后续消息先查 output 落盘）。
- daemon 落盘后打印 `ROUND_COMPLETE` 标记；等待以文件出现为准，与守护退出解耦。

## 2.0.0 (2026-10-12)

网页交互模式（align-board）：

- 新增 `assets/align-board.html`——交互对齐看板：🎯 目标卡片 / ❓ 要你定（单选 chips、是否按钮、多选、文本输入）/ 🧾 假设开关（关掉即喊停）/ ⚡ 盲区分级警示 / ✅ 验收可追加 / 🤝 契约展示；顶部对齐进度条，「按默认开工」≡ 回 OK，一键提交回传 Agent；提交失败自动降级为可复制 JSON。
- 新增 `scripts/align-daemon.mjs`——本地守护进程：托管看板并注入 boot 数据，`POST /submit` 落盘 `align-output.json` 后自动退出唤醒 Agent；输出已存在时拒启动防重复轮次。
- SKILL.md 新增网页模式章节：align-input.json / align-output.json 协议、Agent 四步流程、降级链（网页 → 文本简报 → 复制 JSON 回贴）；文本简报保留为降级路径，内容同源、编号互通。

## 1.0.0 (2026-09-28)

初版：三档分诊（跳过/简报/访谈）、对齐简报固定视觉语法（≤26 行，10 秒扫完回一行）、盲区三级分级（🔴 阻断/🟡 建议/⚪ 科普）、契约 R1-R3 自动履行、访谈模式 3 轮 ×3 问与共识清单落盘、反模式硬约束。
