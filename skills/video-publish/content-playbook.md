# 内容编排与吸引力 Playbook

video-publish 的内容侧规范：分镜怎么排、口播怎么写、包装参数用什么值、投稿元数据怎么填。技术与流程见 SKILL.md，本文件只管"好看、留人、合规"。

核心公式一句话：**承诺（3 秒钩子）→ 推进（每镜一个信息点 + 悬念链）→ 回收（结尾兑现 + 资源沉淀）**。

---

## 1. 分镜结构模板

### 60-120 秒演示/科普视频（默认）

| 镜 | 占比 | 任务 | 要点 |
|----|------|------|------|
| s1 钩子 | 0-3s 内出钩 | 给"继续看的理由" | 强对比大字卡；口播第一句含具体名词+数字；禁自我介绍/片头 logo |
| s2 语境 | ~10% | 一句话交代来源/身份 | 删铺垫，直接建立信任（谁做的、为什么可信） |
| s3-s5 推进 | ~65% | 每镜一个信息点 | 交替使用：数据镜、对比镜、实操镜；每 30 秒至少一个信息增量 |
| s6 兑现 | ~15% | 回收开头悬念 | 展示最终结果，直接回答 s1 提出的问题 |
| 末镜（id=s8） | ~10% | 总结+资源+软引导 | 适用/不适用清单、链接、一句三连软引导、下期钩子 |

### 长知识视频（8-15 分钟）三段式

- 认知颠覆（前 20%）：反常识观点开场
- 方法论拆解（中 60%）：分步演示 + 动态图示，每 3 分钟一个高能点
- 资源沉淀（后 20%）：工具清单/命令/代码库——驱动收藏（收藏在三连里权重最高）

### 节奏硬指标

- 画面视觉变化每 **2-4 秒**一次（幻灯片管线 = 换版式/加高亮/进度条推进）
- 静态画面 >2 秒完播率降 15%；末帧定格（tpad）不超过段长的 40%
- 口播每秒 3-4 字（中文）；单句 ≤15 字
- 主线知识点 3-5 个，多了观众记不住
- 1.5 倍速自检：加速看仍拖沓的段落必删

## 2. 前 3 秒钩子库

有效度实测排序：**痛点直击 > 反常识 > 结果前置 > 疑问聚焦 > 数字悬念 > 身份共鸣 > 反差对比**。垫底：打招呼/自我介绍/黑屏 logo/铺垫。

| 类型 | 句式模板 | 示例 |
|------|----------|------|
| 痛点直击 | "你是不是也 X？我试了 N 次…" | "播放量卡在 500？3 个模板解决" |
| 反常识 | "X 不做 Y，反而 Z" | "这个 AI 不回答问题，它向你提问" |
| 结果前置 | 最炸结果 + 反差数字 | "0.6 秒返回，一次调用万分之一美分" |
| 疑问聚焦 | 精准问题（非"你知道吗"） | "为什么越熟悉的知识点越容易忘？" |
| 数字悬念 | "90% 的人都做错了" | 具体数字制造信息差 |
| 身份共鸣 | "打工人快进来学" | 锁定人群即停留 |

规则：
1. 第一句 3 秒内出现**具体名词和数字**（"很好用"大脑不处理；"3 个模板/0.042 美元"才是信息）
2. 先说观众损失，再给解药（顺序反了留存掉）
3. 信息缺口 **5 秒内开始兑现**，10 秒不兑现 = 标题党
4. 钩子视觉：高对比字卡，推荐"灰色删除线否定句 vs 高亮肯定句"结构（例：~~AI 抢着回答问题~~ → **这个 AI 向你提问**）
5. 封面截自/呼应前 3 秒高光帧，降低点击后心理落差

## 3. 口播稿（narration）写作检查单

写完逐条对照，不达标重写：

- [ ] s1 第一句 = 钩子句（含具体名词+数字），无任何铺垫/问候
- [ ] 每镜只讲**一个**信息点，携带数字、对比或实操
- [ ] 每镜结尾埋一个通向下一镜的悬念（"但价格才是最离谱的"）
- [ ] 每镜字数 = 目标秒数 × 3~4（20s 镜 ≈ 60-80 字）
- [ ] 单句 ≤15 字，长短句混搭
- [ ] 禁用：首先/其次/最后/综上所述/赋能/沉淀/底层逻辑
- [ ] 抽象概念配具象类比+动词（"API 像外卖小哥，不进门只把餐递到门口"）
- [ ] 禁"强大/先进/极其"类形容词，换可感知量词（"3 秒响应""比发微信图片还快"）
- [ ] 中段每 30 秒一个小反转/小福利（"这里 90% 的人都做错"）
- [ ] 末镜有：结果回收 + 一句三连软引导（"觉得有用点个赞"）+ 资源指引（命令链接在简介）
- [ ] 结尾留钩子：下期预告或开放话题

## 4. 视听包装参数

### 字幕（ass 烧录）

- 粗黑体白字 + 2px 黑描边；字号 ≈ 画面宽 1/6；一句一行
- 位置：底部 20% 安全区（1080p 下 y≥864 区域），不压关键内容
- 关键词高亮色（数字/价格/产品名用亮色）：Catppuccin 风配蓝 #89b4fa / 绿 #a6e3a1 / 黄 #f9e2af
- 关键信息停留 ≥1.5s；无口播的纯画面段落不放字幕

### BGM（compose 可选增强）

- 纯音乐、鼓点清晰、BPM 100-120、前奏 ≤3s；单视频一首不换
- 音量 = 人声的 8%-12%（演示类可到 20%）
- 自动闪避：`sidechaincompress=threshold=0.02:ratio=9:attack=200:release=500`，duck -12dB
- 1s 淡入淡出；版权用 B 站创作中心曲库（投稿时不内嵌 BGM 最稳）

### 音效

- 转场 whoosh（-20dB / 0.3s）、关键词弹出 ding、章节切换 click
- 全部后期加，生成阶段不混音

### 响度与画质

- 成片响度：`loudnorm=I=-14:LRA=11:TP=-1.5`（B 站/抖音通用 -14 LUFS）
- H.264 + AAC，1080p 码率 10-15Mbps（CRF 21 已够网络投稿）
- 转场 80% 硬切，全片转场特效 ≤2 种；片头 0.5s 呼吸再上字幕，片尾 1s 淡出

## 5. 封面与标题

### 标题公式

**痛点 + 解决方案 + 数据锚点**，核心关键词前置（B 站标题前 15 字参与搜索匹配）：

- 《月薪 5K 如何靠 AI 月入 3W？这 3 个工具让我少走 100 小时弯路》
- 《Jev：会向你提问的 AI！三种新题型 + OpenRouter 真实调用实测》
- 感叹/疑问句优于陈述句；具体 > 华丽；80 字上限但前 15 字定生死

### 封面

- 高对比配色：暗底 + 单一亮色高亮（橙黑/蓝黄/暗紫底+粉字）
- 主标题大字（占宽 60%+）+ 副标题价值点（"附资源包""真实调用实测"）
- 信息分层：主视觉 → 大字 → 小标签；缩略图尺寸下主信息仍可读
- 从前 3 秒高光帧取材保持视觉一致；HTML 模板 + Chromium 截图产出（背景图用 data URL 嵌入）

## 6. 投稿元数据模板（B 站）

### 简介 desc 结构

```
一句话价值主张（含关键词）

核心内容 2-3 句（含关键数字）

实操/命令区（代码、时间戳）
00:00 章节1
00:17 章节2
…

链接资源（官网/文档/仓库——驱动收藏）

合规声明：本视频旁白由 AI 生成（Edge-TTS），画面为程序化生成/真实录屏
```

### 标签策略

- 前 3 个标签 = 核心搜索词（B 站标签前 3 位权重高）
- 大词 + 长尾词组合："AI,大模型,LLM,SystemOne,OpenRouter,API,人工智能"
- 参考同领域爆款视频的公共标签

### 分区 tid（以 member API 实测为准）

`GET member.bilibili.com/x/vupre/web/archive/pre`（带 cookie）→ `data.typelist` 为全量权威表。已验证：科技=188，其下 95 数码 / 230 软件应用 / **231 计算机技术** / 232 科工机械 / 233 极客DIY。

### 发布后

- 提醒用户勾选「AI 生成内容」声明（API 无法代勾，2025-09 标识办法合规要求）
- 置顶一条引导评论；72 小时内盯 5 秒跳出率（>45% 改开头）与互动率（<5% 加引导）
